# alvin-k-tay.github.io

Personal academic site, served by GitHub Pages from the `main` branch.

- `index.html` — the single page (bio, projects, publications).
- `assets/css/style.css` — styling.
- `assets/images/alvin-tay-2026.jpg` — profile photo. Use a new file name when replacing it, so browsers do not show a cached copy.

The publication list is generated from OpenAlex (author `A5028315598`, matched to ORCID 0000-0002-9330-3929). To refresh it, re-run the build script against a fresh `works.json` download and commit the new `index.html`.
